# 深渊回廊 —— 试炼模式体检报告与改造方案

> 反馈来源：玩家「试炼模式太鸡肋了，都没什么想点进去的欲望」
> 体检方式：逐行审查 `试炼程序.js`（2364 行）、`主程序.js` 中试炼相关逻辑、`主界面.html` 试炼界面结构，全部结论基于代码事实。

===============================================================
## 一、试炼模式现状（玩法全貌）
===============================================================

【入口】经典模式顶栏红色按钮「进入试炼」（主界面.html L78）。
  前置条件：已选英雄、无待选增益。

【流程】
1. 进入时备份玩家状态（试炼程序.js L160-166），试炼内使用副本，
   退出时恢复（L1526-1563）→ 试炼失败/退出**不影响**经典模式。
2. 限回合挑战：攻击/防御/喝药各消耗 1 回合。
   回合上限：简单45 / 普通38 / 困难33 / 地狱30，支持自定义面板
   调整（L71-84）。
3. 每层 3 个房间：
   - 房间1：50% 普通 / 50% 镜像
   - 房间2：50% 精英 / 30% 镜像 / 20% 普通
   - 房间3：Boss（层主 N，或 30% 概率影之皇）
4. 每层结束惩罚：扣 3 血（保底 1）+ 随机诅咒（10 种池，不重复）。
5. 点数：普通 1 / 精英 2 / Boss 5，贪婪诅咒减半，试炼印记遗物 +1，
   结束时剩余回合折算 0.5 点/回合。
6. 狂怒：上限 10，攻击/防御/药水各 +1，满后手动爆发（L1879）。
7. 商店（试炼点数唯一消费端）：
   - 常驻强化（越买越贵）：攻击+2 / 生命+6 / 荆棘+1 / 吸血+1 / 暴击伤害+3%
   - 遗物解锁（一次性）：7 件，20~35 点
   - 特殊商品：时光沙漏（回合+10，30 点）、狂怒燃料（12 点）
8. 结束：死亡 或 回合耗尽 → 开商店 → 手动「退出试炼」回经典模式。

【永久强化的作用范围（关键事实）】
`applyTrialUnlocks()`（L87-105）只把加成加在 `_state.player` 上，
而 `_state.player` 仅在 `startTrial` 复制数据时被读取一次，试炼战斗
全程使用独立副本 `trial.player`；退出时 `_state.player` 被备份还原。
→ **试炼商店买的一切，经典模式完全吃不到，只在试炼内生效。**

===============================================================
## 二、经济账体检（为什么"变强"感知 ≈ 0）
===============================================================

【收入端】
- 每层完整打通 ≈ 1 + 1.5 + 5 = **7.5 点**（见房间生成概率）
- 一局 38 回合（普通）按打 3~5 层估算 ≈ 22~37 点，加剩余回合
  奖励 ≈ **30~45 点/局**

【支出端】
- 常驻强化：10~16 点起价，**每买一次 +5~10 涨价**
- 遗物：20~35 点
- 时光沙漏：30 点

【结论】
打满一局（约 10 分钟+）只够买 **1 件遗物 或 2 件基础强化**。
而基础强化是「攻击 +2」「生命 +6」——经典模式后期攻击几十上百、
生命几百，+2/+6 连一次攻击的零头都不到。且这些加成**只在试炼内
生效**，回到经典模式后玩家看不到任何变化。
→ 付出 10 分钟，得到"+2 攻击（仅试炼内）"，感知约等于零。

===============================================================
## 三、根因诊断（鸡肋感的 7 个来源）
===============================================================

1. **奖励感知极弱**：永久强化全是微数值，且与经典模式隔离，
   玩家在试炼外完全感受不到成果。这是鸡肋感的头号来源。
2. **正反馈间隔太长**：一局 30~45 点，中间没有任何小奖励节点，
   只有结束时一次商店，而那次商店还大概率买不起好东西。
3. **没有目标感**：无段位/里程碑/最高层数记录，玩家不知道
   "打到第几层算强、为什么要继续打"。
4. **无独特性**：试炼玩法 = 经典战斗 + 回合倒计时 + 诅咒惩罚，
   没有试炼专属的机制爽点，是"换皮 + 加压"。
5. **负反馈过重**：层扣血 + 诅咒累积 + 回合倒计时三重压力叠加，
   收益又低，打完只有"受苦"感。
6. **无惊喜节点**：击败敌人只有"获得 1 试炼点"的日志，无掉落、
   无稀有奖励、无稀有事件。
7. **入口无吸引力**：按钮就四个字「进入试炼」，不展示当前段位、
   本周进度、待领奖励，玩家没有点击冲动。

【额外发现：疑似 Bug —— 镜像房间被静默跳过】
- `generateTrialRooms()` 会生成 `'mirror'` 类型房间（L312/315/318），
  `startTrialCombat()` 也完整实现了镜像战斗逻辑（L449-478）。
- 但 `enterTrialRoom()`（L340）进入战斗的判定只包含
  `enemy / elite / boss` 三种类型，**mirror 不在其中**。
- 结果：镜像房间必然走 else 分支 → `resolveTrialRoom()` → 打印
  "试炼中遇到未知房间，跳过" → 直接跳过该房间。
- 影响：房间1/房间2 有 30%~50% 概率**根本没有战斗**，直接跳层；
  镜像怪、复制法师、mirror BGM 场景全部是死代码。
- 这也部分解释了玩家"试炼没东西可打"的体感——层数推进异常快，
  内容密度比设计意图低得多。

## 四、改造方案（分优先级，可逐步落地）
===============================================================

### 方案 A：里程碑 + 段位系统（推荐优先，收益最大）
给试炼装上"长期目标 + 即时惊喜"，改动集中在 `试炼程序.js` 与
`主界面.html`，不碰战斗数值，风险低。

- **层数里程碑**：首次到达第 3/5/8/10/15 层时，弹横幅 + 大额试炼点
  + 永久称号（如「深渊新兵」「深渊征服者」）。
- **累计点数段位**：按历史累计试炼点升级（青铜→白银→黄金→深渊），
  每升一段解锁一项一次性大奖励（如攻击+10、生命+30、新遗物）。
- **历史记录**：存档新增 `trialHistory`（最高层数/累计点数/局数），
  试炼界面常驻展示"最高层数"作为自我挑战目标。
- **入口状态**：顶栏按钮显示当前段位徽章 + 本周累计点数，制造
  点击欲望。

### 方案 B：商店商品重做（让每笔消费有存在感）
把微数值商品升级为质变效果：
- 新增「点数获取率 +25%/+50%」永久加成（直接解决攒点慢）。
- 新增「开局自带 X 试炼点」「每层开始获得 1 试炼点」类遗物。
- 把「攻击 +2」系列改成阶梯式大件（如「深渊之力：攻击 +10」，
  单价高、效果显著）。
- 新增与经典模式联动的消费端（可选，效果最大）：
  试炼点可兑换经典模式的金币/经验加成，打通两模式闭环。

### 方案 C：试炼专属机制（强化爽点，中期工作量）
- **连杀加成**：连续击杀不受伤时，试炼点奖励 +1/+2/+3 递增，
  断链重置 —— 给玩家"极限操作"的追求。
- **无伤层奖励**：某层 3 房间全无伤通过，额外 +3 点。
- **速通奖励**：剩余回合 > 50% 时额外结算大额点数，鼓励快攻。
- **狂怒加速**：狂怒获取翻倍（攻击 +2 怒），爆发更频繁，爽点前置。

### 方案 D：修复镜像房间 Bug（必须做，无论选哪个方案）
`enterTrialRoom()` 的战斗判定补上 `mirror` 类型，让镜像战斗、
复制法师、mirror BGM 真正生效。改动 1 行，内容密度立刻回升。

### 方案 E：风险对冲（可选）
把"每层扣 3 血 + 诅咒"改为部分惩罚可被奖励抵消，例如：
- 无伤层免除本层扣血；
- 新增「深渊祝福」随机正面事件与诅咒池对冲。

===============================================================
## 五、实施路线建议
===============================================================

- 第一步（必做，半天）：修镜像 Bug（方案 D），内容密度立刻回升。
- 第二步（推荐）：方案 A 里程碑 + 段位 + 历史记录 + 入口展示，
  直接解决"没目标、没欲望"。
- 第三步（按反馈）：方案 B 商店重做，把微数值换成质变。
- 第四步（可选）：方案 C 专属机制，锦上添花。
- 每步完成后自测：新开一局进试炼验证；旧存档读取不报错；
  退出试炼后经典模式数值与进入前一致。

## 六、附：代码体检发现的其他小问题
===============================================================

1. `handleTrialEnemyDefeat` 每场胜利后重复调用 `applyTrialUnlocks()`
   （L820），会给 `_state.player` 反复叠加永久加成直到退出。虽然
   退出时被备份覆盖、无实际伤害，但属于多余调用/隐患，建议删除
   该行或改为对 `trial.player` 生效。
2. 试炼结束时（`endTrial` → 商店）若玩家直接关闭浏览器，永久
   加成数值残留风险同上，统一收口到"退出时恢复"更稳妥。
3. 图鉴中「试炼永久加成」描述为"永久攻击 +1"，但实际只在试炼内
   生效，措辞容易让玩家误以为强化经典模式，建议在图鉴描述里注明
   "仅试炼模式生效"。
